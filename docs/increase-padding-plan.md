# Increase Padding Plan

## Ziel

- Die vertikalen Abstaende zwischen den Hauptelementen der Marketing-Sections spuerbar vergroessern.
- Jede Section einzeln abarbeiten, damit die Workload klein und reviewbar bleibt.
- Bestehendes Design beibehalten; Fokus liegt auf Padding, Gap, Margin und ruhigerer vertikaler Komposition.

## Effekt-Check

- Geprueft: `animation_mockups/effects-catalog.json`
- Ergebnis: Fuer diesen Task kein neuer Effekt noetig.
- Begruendung: Die Aufgabe ist ein Spacing-/Kompositions-Refinement und kein Interaktions- oder Motion-Umbau.

## Umsetzungsregel pro Section

- Erst nur eine Section anfassen.
- Section-spezifische Headline-, Summary-, Grid- und Abschluss-Abstaende vergroessern.
- Mobile und Desktop beide pruefen; Desktop darf deutlich luftiger werden, Mobile nur kontrolliert.
- Kein Redesign, keine neue Motion, keine neue Informationsarchitektur ohne explizite Nachfrage.
