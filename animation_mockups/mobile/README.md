- `bottom-sheet-snap/` (draggable Bottom Sheet mit Snap-States)

- touch-first Interaction (ohne Hover-Abhaengigkeit)
- geringe GPU/CPU-Last auf Mid-Range-Geraeten
- gute Lesbarkeit und Bedienbarkeit bei kleinen Viewports
