# P1-T24.1 — Leads-Tabelle: Spaltenredesign + Social-Profiles + Updated-Spalte

> **Sub-Plan zu** `plans/workspace/leads/01-list-and-detail.md` (T24).
> **Branch:** aktuell `feat/workspace-lead-section` (weiterführend)
> **Geschätzter Aufwand:** ~3–4h

## Context

Die in T24 gebaute Leads-Tabelle (`src/components/workspace/leads/table/leads-table-row/leads-table-row.tsx`) hat eine \*
\*überladene "Lead"-Spalte\*\*: Avatar + Name + Sekundär-Label (`websiteUrl ?? email`) + zweite URL-Zeile mischen drei
semantisch unterschiedliche Informationen in einem Cell. Außerdem fehlt der für tägliches Arbeiten wichtigere
`updatedAt`-Wert (aktuell wird nur `createdAt` angezeigt) und Sozial-/Kontakt-Verfügbarkeiten (LinkedIn, Instagram,
YouTube, Phone, Website) sind in der Liste nicht erkennbar — der Nutzer muss jeden Lead einzeln öffnen.

Ziel dieses Sub-Plans:

1. **Lead-Spalte schlank** auf Initialen + Name + E-Mail reduzieren.
2. **Neue Spalte "Social Profiles"** mit Brand-farbigen, klickbaren Icons (LinkedIn, Instagram, YouTube, Website-Globus,
   Phone). Klick öffnet `target="_blank"`; Phone öffnet `tel:`.
3. **Neue Spalte "Updated"** zusätzlich zu "Created", sortierbar, im Format `vor X Std.` / `vor X Tagen` (>30 Tage
   absolutes Datum), mit Tooltip via `title`.

User-Entscheidungen aus Phase 3 (festgehalten):

| Frage               | Entscheidung                                                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Inline-Aufklappen?  | **Nein** — nur Spalten umbauen; Detail-Panel bleibt via `?selected=`                                                           |
| Created vs Updated? | **Beide Spalten** zeigen, beide sortierbar                                                                                     |
| Website-URL?        | **Globus-Icon** in Social-Profiles-Spalte (kein eigener "Web"-Spalte)                                                          |
| Zeitformat?         | <1h `gerade eben`; <24h `vor X Std.`; <30 Tagen `vor X Tagen`; sonst absolutes Datum (medium); Tooltip mit vollständigem Datum |

## Architektur-Entscheidungen

**Daten-Layer.** `LeadSummaryDto` muss um `phone: string | null` und `socialProfiles: LeadSocialProfileDto[]` erweitert
werden, damit die Tabelle ohne Detail-Roundtrip rendern kann. Der `listLeads`-Query-Handler holt die Social-Profiles in
**einer separaten zweiten Query** (kein JSON-Aggregation-Subquery), gruppiert per `lead_id` und mergt im Mapping.
Begründung: Drizzle-`leftJoin`+`groupBy` mit Array-Aggregation würde komplette Row-Duplikate erzeugen oder `array_agg`
benötigen — die zweite Query ist einfacher, in P1 mit `LEAD_LIST_PAGE_SIZE = 25` performant, und passt zum bestehenden
Pattern (`get-lead-by-id.query-handler.ts` macht es genauso).

**Sort-Erweiterung.** `LeadSort` bekommt `UpdatedAsc` / `UpdatedDesc`. Default-Sort bleibt `CreatedDesc` (kein
Verhaltenswechsel ohne Migration der bestehenden URLs). Filter-Schema (`lead-filter.schema.ts`) akzeptiert das aus
`LEAD_SORT_VALUES` automatisch via `z.enum`.

**Icons.** Brand-Icons (LinkedIn, Instagram, YouTube) kommen aus `@fortawesome/free-brands-svg-icons` (bereits
installiert, siehe `package.json`). Globus + Phone werden **inline-SVG** rendert — Pattern existiert bereits in
`lead-source-badge.tsx`. **Kein neues npm-Paket** (insbesondere kein `free-solid-svg-icons`).

**Brand-Farben** als CSS-Variablen im Komponenten-CSS-Modul:

- LinkedIn `#0A66C2`
- Instagram `#E4405F` (Solid-Color, kein Gradient — bessere Konsistenz mit kleinen Icons)
- YouTube `#FF0000`
- Globus / Phone: bestehende Theme-Tokens (`--color-text-muted` Default, `--color-cta` Hover)

**Relative-Time.** Reine Funktion in `src/lib/format-relative-time.ts` (kein `date-fns`/`dayjs`). Drei Schwellen: <
60min → "gerade eben"-Schlüssel; <24h → Stunden; <30d → Tage; sonst Fallback auf
`Intl.DateTimeFormat(..., { dateStyle: "medium" })`.

`src/server/workspace/leads/query-handler/list-leads.query-handler.ts`:

```ts
import { count, eq, inArray } from "drizzle-orm";
import { getDrizzleDatabaseClient } from "@/server/db/core";
import {
  leadCategories,
  leadSocialProfiles,
  leads,
} from "@/server/db/record-configuration";
import type { LeadFilterInput } from "@/server/workspace/leads/services/lead-filter/lead-filter.schema";
import { mapLeadRowToSummaryDto } from "@/server/workspace/leads/services/lead-summary/lead-summary-mapping-service";
import type { LeadSocialProfileDto } from "@/common/contracts/leads/lead-social-profile.dto";
import type { ListLeadsResult } from "@/common/contracts/leads/results/list-leads-result";
import { buildLeadFilter } from "./lead-filter.query-handler";

export async function listLeads(
  filter: LeadFilterInput,
): Promise<ListLeadsResult> {
  const db = getDrizzleDatabaseClient();
  const { where, orderBy, limit, offset, page, perPage } =
    buildLeadFilter(filter);

  const [countRows, rows] = await Promise.all([
    db.select({ count: count() }).from(leads).where(where),
    db
      .select({
        id: leads.id,
        first_name: leads.first_name,
        last_name: leads.last_name,
        company_name: leads.company_name,
        email: leads.email,
        phone: leads.phone,
        website_url: leads.website_url,
        score: leads.score,
        source: leads.source,
        lead_status: leads.lead_status,
        owner: leads.owner,
        created_at: leads.created_at,
        updated_at: leads.updated_at,
        category_id: leads.category_id,
        category_slug: leadCategories.slug,
        category_label_key: leadCategories.label_key,
      })
      .from(leads)
      .leftJoin(leadCategories, eq(leads.category_id, leadCategories.id))
      .where(where)
      .orderBy(orderBy)
      .limit(limit)
      .offset(offset),
  ]);

  const leadIds = rows.map((row) => row.id);
  const socialProfileRows = leadIds.length
    ? await db
        .select({
          id: leadSocialProfiles.id,
          lead_id: leadSocialProfiles.lead_id,
          platform: leadSocialProfiles.platform,
          profile_url: leadSocialProfiles.profile_url,
          normalized_url: leadSocialProfiles.normalized_url,
        })
        .from(leadSocialProfiles)
        .where(inArray(leadSocialProfiles.lead_id, leadIds))
    : [];

  const socialByLead = new Map<string, LeadSocialProfileDto[]>();
  for (const row of socialProfileRows) {
    const list = socialByLead.get(row.lead_id) ?? [];
    list.push({
      id: row.id,
      platform: row.platform,
      profileUrl: row.profile_url,
      normalizedUrl: row.normalized_url,
    });
    socialByLead.set(row.lead_id, list);
  }

  return {
    rows: rows.map((row) =>
      mapLeadRowToSummaryDto(row, socialByLead.get(row.id) ?? []),
    ),
    total: Number(countRows[0]?.count ?? 0),
    page,
    perPage,
  };
}
```

function buildOrderBy(sort?: LeadSort): SQL {
  switch (sort) {
    case LeadSort.CreatedAsc:
      return asc(leads.created_at);
    case LeadSort.UpdatedAsc:
      return asc(leads.updated_at);
    case LeadSort.UpdatedDesc:
      return desc(leads.updated_at);
    case LeadSort.ScoreAsc:
      return asc(leads.score);
    case LeadSort.ScoreDesc:
      return desc(leads.score);
    case LeadSort.NameAsc:
      return asc(leads.last_name);
    case LeadSort.NameDesc:
      return desc(leads.last_name);
    case LeadSort.CreatedDesc:
    default:
      return desc(leads.created_at);
  }
}

`src/lib/format-relative-time.ts`:

export type RelativeTimeDictionary = {
  justNow: string;
  hoursAgo: string;
  daysAgo: string;
};

const HOUR_MS = 60 * 60 * 1000;
const DAY_MS = 24 * HOUR_MS;
const ABSOLUTE_THRESHOLD_DAYS = 30;

function interpolate(template: string, count: number): string {
  return template.replace("{count}", String(count));
}

export function formatRelativeTime(
  locale: string,
  iso: string,
  dictionary: RelativeTimeDictionary,
): string {
  const target = new Date(iso).getTime();
  const diffMs = Date.now() - target;

  if (diffMs < HOUR_MS) {
    return dictionary.justNow;
  }

  if (diffMs < DAY_MS) {
    const hours = Math.floor(diffMs / HOUR_MS);
    return interpolate(dictionary.hoursAgo, hours);
  }

  const days = Math.floor(diffMs / DAY_MS);
  if (days < ABSOLUTE_THRESHOLD_DAYS) {
    return interpolate(dictionary.daysAgo, days);
  }

  return new Intl.DateTimeFormat(locale, { dateStyle: "medium" }).format(
    new Date(iso),
  );
}
```

import type { MouseEvent } from "react";
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome";
import {
  faInstagram,
  faLinkedinIn,
  faYoutube,
} from "@fortawesome/free-brands-svg-icons";
import type { LeadSocialProfileDto } from "@/common/contracts/leads/lead-social-profile.dto";
import type { LeadSocialPlatform } from "@/common/constants/leads/lead-social-platforms";
import styles from "./lead-social-profiles.module.css";

type SocialIconLabels = {
  website: string;
  linkedin: string;
  instagram: string;
  youtube: string;
  phone: string;
};

type LeadSocialProfilesProps = {
  websiteUrl: string | null;
  phone: string | null;
  profiles: LeadSocialProfileDto[];
  labels: SocialIconLabels;
  emptyLabel: string;
};

const platformIcon: Record<LeadSocialPlatform, typeof faLinkedinIn> = {
  linkedin: faLinkedinIn,
  instagram: faInstagram,
  youtube: faYoutube,
};

function stopPropagation(event: MouseEvent) {
  event.stopPropagation();
}

function GlobeSvg() {
  return (
    <svg
      aria-hidden="true"
      className={styles.icon}
      viewBox="0 0 16 16"
      fill="none"
      stroke="currentColor"
      strokeWidth="1.5"
    >
      <circle cx="8" cy="8" r="6.25" />
      <path d="M1.75 8h12.5M8 1.75c2 2 2 10.5 0 12.5M8 1.75c-2 2-2 10.5 0 12.5" />
    </svg>
  );
}

function PhoneSvg() {
  return (
    <svg
      aria-hidden="true"
      className={styles.icon}
      viewBox="0 0 16 16"
      fill="currentColor"
    >
      <path d="M3.654 1.328a.678.678 0 0 0-1.015-.063L1.605 2.3c-.483.484-.661 1.169-.45 1.77a17.6 17.6 0 0 0 4.168 6.608 17.6 17.6 0 0 0 6.608 4.168c.601.211 1.286.033 1.77-.45l1.034-1.034a.678.678 0 0 0-.063-1.015l-2.307-1.794a.68.68 0 0 0-.78-.062L9.78 11.04a18 18 0 0 1-2.812-2.327A18 18 0 0 1 4.642 5.9l.945-1.83a.68.68 0 0 0-.062-.78z" />
    </svg>
  );
}

export function LeadSocialProfiles({
  websiteUrl,
  phone,
  profiles,
  labels,
  emptyLabel,
}: LeadSocialProfilesProps) {
  const hasAny = Boolean(websiteUrl) || Boolean(phone) || profiles.length > 0;

  if (!hasAny) {
    return <span className={styles.empty}>{emptyLabel}</span>;
  }

  return (
    <div className={styles.container}>
      {websiteUrl ? (
        <a
          aria-label={labels.website}
          className={styles.iconLink}
          data-platform="website"
          href={websiteUrl}
          onClick={stopPropagation}
          rel="noreferrer"
          target="_blank"
          title={labels.website}
        >
          <GlobeSvg />
        </a>
      ) : null}
      {profiles.map((profile) => (
        <a
          aria-label={labels[profile.platform]}
          className={styles.iconLink}
          data-platform={profile.platform}
          href={profile.profileUrl}
          key={profile.id}
          onClick={stopPropagation}
          rel="noreferrer"
          target="_blank"
          title={labels[profile.platform]}
        >
          <FontAwesomeIcon
            className={styles.icon}
            icon={platformIcon[profile.platform]}
          />
        </a>
      ))}
      {phone ? (
        <a
          aria-label={labels.phone}
          className={styles.iconLink}
          data-platform="phone"
          href={`tel:${phone.replace(/\s+/g, "")}`}
          onClick={stopPropagation}
          title={labels.phone}
        >
          <PhoneSvg />
        </a>
      ) : null}
    </div>
  );
}
```
